Trzy sposoby dodawania CSS

1 — Styl zewnętrzny (zalecany)

Style przechowywane w osobnym pliku .css, linkowanym w sekcji <head>. Pozwala zarządzać wyglądem wielu stron z jednego miejsca.

<link rel="stylesheet" href="styl.css">

2 — Styl wewnętrzny

Style pisane bezpośrednio w sekcji <head> w znaczniku <style>. Dotyczy tylko jednej strony.

<style>
  p { color: red; }
</style>

3 — Styl liniowy (inline)

Dopisywany bezpośrednio w znaczniku HTML atrybutem style. Najtrudniejszy do utrzymania.

<p style="color: red; font-size: 14px;">Tekst</p>

Budowa reguły CSS

selektor {
    właściwość: wartość;
    właściwość2: wartość2;
}
