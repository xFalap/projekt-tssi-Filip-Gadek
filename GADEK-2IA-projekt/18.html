Co to jest dziedziczenie?

Dziedziczenie w CSS oznacza, że część właściwości elementu nadrzędnego jest automatycznie przejmowana przez elementy potomne. Dzięki temu nie trzeba pisać tych samych reguł wielokrotnie.

Przykład

body {
  color: blue;
  font-family: Arial, sans-serif;
}

Elementy znajdujące się wewnątrz znacznika body odziedziczą kolor tekstu i krój czcionki.

Najczęściej dziedziczone właściwości

  • color
  • font-family
  • font-size
  • font-style
  • font-weight
  • line-height
  • text-align

Wymuszenie dziedziczenia

p {
  color: inherit;
}

Podsumowanie

Dziedziczenie upraszcza tworzenie i utrzymanie arkuszy stylów CSS, ponieważ pozwala ograniczyć ilość powtarzanego kodu.
