Co to HTML i CSS?

HTML (HyperText Markup Language) to hipertekstowy język znaczników, który służy do tworzenia dokumentów hipertekstowych — stron internetowych.

CSS (Cascading Style Sheets) to kaskadowe arkusze stylów — język służący do opisywania formy prezentacji stron WWW.

Podstawowa struktura dokumentu HTML

Każdy poprawny dokument HTML ma następującą strukturę:

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Tytuł strony</title>
</head>
<body>
    Treść strony...
</body>
</html>

Opis znaczników

  • <!DOCTYPE html> — deklaracja typu dokumentu (HTML5)
  • <html> — korzeń dokumentu, atrybut lang określa język
  • <head> — metadane, tytuł, linki do CSS i skryptów
  • <body> — cała widoczna treść strony
