Rodzaje list w HTML

HTML wyróżnia dwa podstawowe rodzaje list. Każdy element listy definiujemy znacznikiem <li>.

  • <ul> — lista nieuporządkowana (wypunktowana)
  • <ol> — lista uporządkowana (numerowana)

Właściwość list-style-type

Właściwość CSS list-style-type zmienia wygląd znaczników (punktorów) listy.

Dla list nieuporządkowanych <ul>

  • disc — pełne koło (domyślne)
  • circle — puste koło
  • square — kwadrat
  • none — brak punktora

Dla list uporządkowanych <ol>

  • decimal — liczby arabskie (1, 2, 3...)
  • lower-roman — małe cyfry rzymskie (i, ii, iii...)
  • upper-roman — wielkie cyfry rzymskie (I, II, III...)
  • lower-alpha — małe litery (a, b, c...)
