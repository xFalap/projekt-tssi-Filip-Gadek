Reguła @keyframes

Animacje CSS definiujemy za pomocą reguły @keyframes, w której opisujemy stany elementu w kolejnych momentach animacji. Nie wymaga JavaScript.

Etapy określamy słowami from/to lub wartościami procentowymi (0%–100%).

@keyframes mojaAnimacja {
  0%   { background-color: #e8380d; transform: scale(1); }
  50%  { background-color: #1a56d6; transform: scale(1.2); }
  100% { background-color: #e8380d; transform: scale(1); }
}
